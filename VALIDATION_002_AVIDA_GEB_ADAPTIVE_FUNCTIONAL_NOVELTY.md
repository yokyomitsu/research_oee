## 1. Why the global hallmark program returned here

[Validation 001](VALIDATION_001_STRINGMOL_ADAPTIVE_FUNCTIONAL_NOVELTY.md) established two finite Stringmol AFN events in run 2:

1. nonreciprocal parasitic exploitation before/by \(90{,}000\); and
2. partner discrimination by \(680{,}000\).

[Analysis 001](ANALYSIS_001_STRINGMOL_STATIC_HISTORY_REANALYSIS.md) then inspected all eight deposited processed histories. It did not establish a later third functional class. Later parasite and defense variants remained within exploitation and discrimination; reciprocal hypercycle semantics were either earlier than the target interval or lacked event-level adaptive establishment when first seen later. That branch therefore returned to the global hallmark program.

The present operation does not reopen Stringmol. Its two-event result is the frozen comparison benchmark.

## 2. Why Avida and Geb were selected

The 2016 York OEE synthesis identified both as unusually strong historical candidates. Avida had produced complex features absent from ancestors, evolved collaboration, and ecological/co-evolutionary results. Geb had passed Bedau–Packard evolutionary-activity tests, including Channon's component-normalized revision, and had reports of emergent social behavior and potentially scalable complexity. These claims make the systems appropriate positive-case targets, but do not validate repeated AFN by themselves.

The same synthesis also states the more demanding target: long evolutionary sequences of evolved artifacts and behaviors had not been conclusively observed. That qualification is decisive here. Platform-wide variety and metric-level activity cannot substitute for an event chronology in one evolving history.

## 3. AFN criteria

The criteria were frozen before classifying candidates.

| Criterion | Required evidence |
| --- | --- |
| N — novelty | The relevant capability or relation was historically absent and then arose in the examined history. |
| F — function | The novelty has a system-grounded causal role, not merely a changed description, genotype, component, or score. |
| H — heredity | Its implementation is transmitted sufficiently for evolutionary selection to act. |
| A — adaptation | The function contributes to differential reproductive success or adaptive persistence. |
| C — class distinctness | Its causal role differs from earlier accepted functional classes in that history. |
| O — recurrence | Multiple accepted N/F/H/A/C events occur at distinct temporal positions in one continuous evolutionary history. |

The local evidence levels are also frozen:

- **F0:** parameter or state optimization;
- **F1:** a new implementation or member of an established function;
- **F2:** a new adaptive functional relation or capability;
- **F?:** unresolved.

The levels are local classification aids, not a universal function theory. A common logical test does not require a common measurement variable across substrates.

## 4. Tokyo Type 1 procedure

Channon 2024 combines five sequential methods:

1. basic evolutionary-activity statistics, asking whether new components appear and persist;
2. component-normalized activity, comparing activity with a neutral or random-selection shadow so persistence has adaptive content;
3. long-term dynamics classification, requiring continuing normalized new activity together with unbounded accumulated adaptive success rather than turnover alone;
4. indefinite-scalability analysis for diversity and complexity by relaxing relevant physical limits and obtaining successively higher empirical bounds; and
5. analysis of the order of that scalability, with higher-order complexity growth posed as the stronger challenge.

Tokyo Type 1 includes both ongoing adaptive novelty and ongoing complexity growth. It is therefore broader in some dimensions and differently operationalized in others than this repository's AFN test.

| Issue | Tokyo Type 1 procedure | Repository event-level AFN |
| --- | --- | --- |
| Novelty object | Components chosen for activity measurement | System-local functional capabilities or relations |
| Adaptation | Normalized persistence/activity above a shadow | Trait/function-linked differential reproduction or adaptive persistence |
| Accumulation | Unbounded total and median cumulative adaptive activity | Not by itself required for a finite AFN event |
| Diversity and complexity | Explicit continuing/scalability requirements | Neither substitutes for a new functional class |
| Functional semantics | Not necessarily reconstructed event by event | Required |
| Heredity | Often implicit in component/activity construction | Required explicitly enough for selection |
| Recurrence | Long-term statistical trend | Temporally ordered class-distinct events |

Thus passing or approaching the Tokyo procedure does not automatically establish repeated AFN, and finite repeated AFN does not automatically satisfy Tokyo Type 1.

## 5. Avida substrate and function space

Avida organisms are heritable self-replicating programs competing for execution time. The platform provides instructions, mutation, scheduling, and resource/reward semantics. The relevant experiments expose different degrees of pre-enablement:

| Experiment | Functional substrate | Pre-enablement classification |
| --- | --- | --- |
| Lenski complex feature | Nine named Boolean operations receive predetermined multiplicative rewards | **STRONGLY ENUMERATED** |
| Zaman host–parasite | The same nine operations define host resource acquisition and task matching defines infection; parasites steal a fixed share of host processing | **STRONGLY ENUMERATED** for task family and **STRUCTURALLY CONSTRAINED** for interaction |
| Goldsby division of labor | Colonies, colony reproduction, Boolean task resources, task-switch costs, communication, and position-sensing instructions are supplied | **STRUCTURALLY CONSTRAINED**; the high-level division strategy is not directly enumerated |
| Fortuna ecological networks | Task matching and treatment-specific antagonistic or mutualistic interaction mappings are supplied | **STRONGLY ENUMERATED** at interaction semantics |

This does not make the evolved implementations trivial. It limits what can count as a new functional class. An unanticipated program for EQU can be historically novel, heritable, and selected while remaining a new member of an externally supplied logic-task family.

## 6. Avida complex-feature evidence

Lenski et al. began with a 50-instruction ancestor able to reproduce but unable to perform any rewarded logic operation. Nine one- or two-input Boolean functions were explicitly rewarded, with larger rewards assigned to functions requiring more NAND operations.

The principal case-study lineage supplies unusually precise historical evidence:

- the final dominant genotype was 83 instructions long, lay 344 mutational steps from the ancestor, and performed all nine operations;
- EQU first appeared at lineage step 111, update 27,450;
- the 110 preceding steps included 45 beneficial, 48 neutral, and 18 deleterious changes;
- 13 of the beneficial steps introduced a logic function absent in the immediate parent, including six task tradeoffs;
- the pivotal mutation producing EQU was beneficial in its realized background, and reversing it removed EQU;
- the first EQU performer used 35 instructions necessary to the phenotype, with 27 of those derived along the lineage;
- EQU arose in 23 of 50 populations when all simpler operations were also rewarded, but in none of 50 populations where EQU alone was rewarded;
- the lineage continued for 233 steps after EQU; by step 306 it performed all nine operations.

The evidential verdict is split by level:

- **N:** directly supported for the lineage's first rewarded logic capability and for EQU as a particular computation.
- **F:** directly supported; an operation causes resource/merit acquisition in the configured ecology.
- **H:** directly supported by genome-lineage reconstruction.
- **A:** directly supported by measured fitness effects, rewards, persistence, and counterfactual mutation tests.
- **C:** one logic-mediated resource-acquisition class is distinct from ancestral replication, but EQU and the other operations are not defensibly independent high-level classes under the frozen criterion. They are different computations inside the same enumerated task/reward family.

Accordingly, the first acquired logic-task capability is **F2** relative to the ancestor. EQU is a striking **F1** extension within that established class, not a second accepted AFN class. Subsequent acquisition of all nine functions does not add class-level recurrence. Replication-rate changes remain F0/F1 unless they introduce another causal reproductive role; this lineage report does not establish one.

## 7. Avida coevolution evidence

Zaman et al. began both hosts and parasites with the simplest operation, NOT, and ran 50 replicate populations for 500,000 updates. Hosts received resources for performing one of nine fixed logic operations. A parasite could infect a host when they shared an operation and then diverted 80% of host CPU cycles.

The paper establishes strong adaptive and complexity results:

- host complexity, measured by the minimum NAND count of the most complex operation performed, rose higher under live coevolution;
- EQU arose in 17 of 50 coevolving populations and zero of 50 parasite-free populations;
- eliminating parasites halfway reduced later host complexity;
- frozen and replayed parasite treatments did not reproduce the full live-coevolution result;
- most hosts specialized on one operation while parasites tended to span four or five;
- hosts acquired, lost, and switched operations as parasite populations tracked earlier host types;
- starting from EQU led hosts to explore simpler operations before returning to the same higher-complexity equilibrium;
- coevolution increased the number of one-mutation paths to alternative operations, supporting an evolvability result.

For the present criterion, this is **Case A: progressively more complex members of a fixed function family**, not Case B: demonstrated creation of new system-grounded roles. The host's role remains resource acquisition combined with escape from task-matched infection. The nine targets and the infection relation are structural features of the experiment. Operation switching is generally F1; complexity change is not a distinct function; expanded one-step accessibility is an evolvability result, not a current adaptive function class.

No continuous replicate is documented as acquiring a sequence of three or more causally distinct roles. The result therefore does not exceed Stringmol.

## 8. Avida collaboration/ecology evidence

Goldsby et al. evolved clonal colonies whose fecundity depended on accumulated resources. With imposed task-switching costs, colonies evolved task specialization and division of labor. Ablation and information-use analyses show that evolved strategies could use messaging, spatial location, and stochastic differentiation. Division of labor was not itself a named rewarded task; it was an emergent organization under supplied colony selection, tasks, switch costs, and communication/sensing affordances.

This is good evidence for one social/collective F2 function in that experiment. The implementation is heritable through the colony's clonal program, and colony-level differential reproduction supplies adaptive evidence. However, the paper does not establish a later class-distinct functional event in the same colony history.

Fortuna et al. obtained evolving ecological-network structures, but phenotypic matching among the nine fixed logic tasks and the antagonistic or mutualistic mappings were configured experimentally. Network turnover and topology therefore do not alone establish new interaction semantics. No continuous event chronology shows several newly originated functional relations.

Crucially, Lenski's EQU lineage, Zaman's host–parasite replicates, Goldsby's colonies, and Fortuna's ecological-network treatments are different experimental histories. Combining their results would measure **Avida's platform repertoire**, not within-history recurrence.

## 10. Avida strongest positive interpretation

The strongest positive reading treats each selected Boolean operation in the Lenski lineage as a distinct function. On that reading, several simpler functions arise before EQU, EQU appears at update 27,450, and further functions arise until all nine are present. Every operation has a definite causal effect, genomic heredity, and measured selection. Zaman further shows continuing selected task switching under reciprocal host–parasite change. Goldsby shows that Avida can also evolve an unprogrammed collective division strategy.

This is strong evidence for evolutionary creativity and a broad platform repertoire. It is not strong enough for repeated AFN under the frozen class criterion because:

1. the nine Boolean targets and their reward family are enumerated in advance;
2. acquiring another operation changes task identity and computational implementation without necessarily changing the ecological role of rewarded resource acquisition;
3. Zaman's infection relation and allowable task phenotypes are predefined;
4. task complexity can rise while functional role remains fixed;
5. Goldsby's social result is a separate experiment, not a later event in the Lenski or Zaman history.

## 11. Avida strongest skeptical interpretation

The skeptical interpretation accepts one genuine historical AFN class—logic-mediated resource acquisition relative to a reproduction-only ancestor—and regards EQU and later operations as progressively complex implementations or members of that class. It treats host switching among the same nine task identities as adaptation within a fixed host–parasite regime, and division of labor as one additional platform capability demonstrated elsewhere.

This account fits all primary observations without denying their adaptive or mechanistic significance. It does not imply that Avida cannot evolve another class. It says only that the reviewed publications do not show more than one class in one continuous history.

## 12. Geb substrate and behavioral space

Geb organisms occupy a two-dimensional toroidal world and carry variable-length developmental genomes that construct recurrent neural controllers. Controller inputs can match nearby organisms' output labels; action outputs include movement/turning, reproduction, and fighting. Variation acts on heritable developmental descriptions, and selection is biotic rather than a direct behavior-scoring objective.

Pre-enablement is best classified as:

\[
\boxed{\text{GENERIC SUBSTRATE ENABLEMENT within STRUCTURALLY CONSTRAINED primitive actions}.}
\]

The primitive motor, reproductive, fighting, and I/O channels are fixed. High-level strategies such as mutual activation, pseudo-species assortment, collective circling, or exploiting another type's signal are not separately named reward targets. Channon also explicitly notes the limitation: all basic interactions were initially specified and not evolvable even though their behavioral organizations were not specified.

## 13. Geb evolutionary-activity evidence

Channon's early application of Bedau–Packard activity statistics classified Geb as unbounded. Channon 2006 then criticized artificial-system normalization and introduced component-normalized activity using shadow populations under random selection.

In Geb, a measured component is approximately an active developmental gene: a production-rule element that survives development and contributes to the neural controller. The revised analysis supports continuing arrival and persistent adaptive activity of such components, and accumulated activity beyond the neutral shadow. Runs extended for millions of timesteps and hundreds of millions of reproduction events; later scalability work used runs lasting years and billions of reproductions.

These results are important, but their evidential object is an active genetic/developmental component. They do not assign those components to successive causal behavioral roles. Therefore:

\[
\boxed{\text{unbounded component-normalized activity}\not\Rightarrow\text{repeated functional-class novelty}.}
\]

## 14. Geb behavioral novelty evidence

Channon & Damper's primary behavioral analysis documents a particularly informative same-run sequence.

First, a dominant species evolved a controller with matching non-action inputs and outputs. Nearby same-type organisms turning in tight circles supplied activation to one another, kept one another moving, mated immediately before killing, and typically placed offspring away from a killer's path. The paper explains why this integrated strategy was advantageous against attackers. It is historically emergent, controller-encoded, and ecologically consequential. At the available resolution, it supports one F2 social interaction/collective defense-reproduction strategy.

Second, a later “rebel” from the same run used inputs matching the dominant species' activation outputs and connected them to fight, reproduce, and turn outputs. It could turn toward dominant individuals while attempting to kill and reproduce. This is a genuine chronological candidate for a different counter-exploitation role.

The rebel does not pass the complete AFN test in the publication. Its controller is heritable and its behavior is causally reconstructed, but the paper does not establish a trait-specific sweep, persistence, reproductive advantage, or displacement sufficient to classify the role as adaptively established. It also remains unclear whether it is a new functional class or a counterstrategy using the already established movement–fight–reproduce interaction regime. Classification: **F?; DISTINCTNESS UNRESOLVED; ADAPTATION PARTIALLY SUPPORTED**.

The primary paper reports later dominant species and changes in action profiles, but also says evolved controllers become difficult to interpret and that later species can often only be described as sharing characteristics of earlier species while differing from them. These are not additional accepted functions.

The 2016 workshop synthesis lists following, fighting, fleeing, mimicking, and matching I/O channels under Geb. The underlying Geb materials more securely document following/assortment, killing non-same, group motion, and rapid turning by a different type. A Channon workshop presentation assigns the broader crawling, fleeing, and mimicking list to “Creatures-like” systems rather than to a resolved Geb sequence. No primary continuous-history chronology was located that turns all of those labels into Geb AFN events. They are therefore not aggregated into the ledger.

## 15. Geb complexity scalability

Channon 2019 varied two explicit bounds: world length, which bounds population size, and maximum neurons per individual. Maximum individual complexity was measured as the diversity/number of active genes involved in neural development.

Scaling either limit alone produced an asymptotic bound. Scaling both together produced successively larger observed maxima to the extent evaluated, with years-long runs and billions of reproductions. The maximum scaled approximately logarithmically with the smaller of maximum population size and maximum neuron count.

This establishes empirical **indefinite scalability of component-based individual complexity to the tested extent**, not indefinite growth in a single fixed-parameter history. It does not by itself establish:

- new adaptive behavior classes;
- temporal functional ordering;
- repeated AFN; or
- ongoing AFN.

The scalable quantity is active-gene diversity in individual neural development. Connecting it to behavioral-class expansion would require event-level semantic evidence not supplied by the metric.

## 17. Geb strongest positive interpretation

The strongest positive reading begins with the first dominant social strategy and then accepts the same-run rebel as a second adaptive role: one strategy creates same-type mutual activation, group motion, assortative reproduction, and defense; the other reads the first strategy's signals to orient attack and reproduction against it. Later species turnover, unbounded component-normalized activity, and indefinitely scalable active-gene complexity could then be read as evidence that further strategies continued to arise beyond what analysts could decode.

This is a serious positive case because the behavior organizations were not named targets and the first two appear in temporal order in one run. It nevertheless falls short of Stringmol's benchmark:

1. the first “event” combines several roles without resolved subevent chronology;
2. the rebel's adaptive establishment is not measured separately;
3. the class boundary between a new counter-role and another strategy within fixed fight/reproduce signaling is unresolved;
4. later controller changes are not semantically reconstructed;
5. activity and complexity metrics cannot fill those event-level gaps.

## 18. Geb strongest skeptical interpretation

The strongest skeptical account accepts one emergent adaptive social strategy, treats the rebel as an interesting but unvalidated counterstrategy, and treats later turnover as component-level adaptive activity within a fixed sensorimotor/interagent regime. It allows that semantic novelty may have escaped the available analysis, but does not infer hidden functions.

This account is explicitly compatible with the authors' observation that later behaviors become hard to identify. The limitation is evidential rather than a claim of system closure.

## 23. Strongest positive-case ranking

For the exact question—class-distinct AFN recurrence within a continuous history—the ranking is:

1. **Stringmol:** two accepted, ordered classes with direct reaction semantics and strong event-linked adaptation.
2. **Avida:** exceptionally precise lineage, heredity, and selection evidence for complex computation, but no second accepted class inside that lineage; distinct social results are experiment-external.
3. **Geb:** generic high-level behavioral enablement, strong long-run component activity, and qualified indefinite complexity scalability; one accepted behavioral class and one same-run second candidate, but weaker event-level adaptation/class evidence.

This ranking is criterion-specific. Geb ranks above the others on some Tokyo Type 1 components; Avida has the strongest mutation-by-mutation lineage reconstruction; neither fact supplies a third within-history AFN class.

## 24. Central decision

\[
\boxed{\text{D — STRINGMOL REMAINS STRONGEST FINITE-AFN CASE}}
\]

Neither Avida nor Geb provides a published continuous history with more compelling repeated AFN than Stringmol's two-event record.

- Avida supports a maximum of one class in any one reviewed history. Its broader platform repertoire must not be concatenated.
- Geb supports one class and a credible second same-run candidate, but the candidate fails complete event-level adaptive establishment and class resolution.
- Stringmol retains two accepted classes, with no claim of ongoingness.

The comparison is sufficiently determinate for decision D. The residual Geb uncertainty does not supply affirmative evidence that exceeds the benchmark.

## 25. Global hallmark implication

The evidence supports:

- **H2 — Several systems support finite AFN, but none in this reviewed set supports ongoing recurrence.** Avida supports at least one event; Geb supports one at moderate strength; Stringmol supports two.
- **H3 — The principal barrier is event-level historical evidence.** Geb's component activity and behavioral candidates are not joined into sufficiently resolved functional lineages; separate Avida experiments cannot be joined.
- **H5 — Important Avida designs structurally predefine much of the functional repertoire.** This is especially strong for the nine logic tasks and task-matched infection. It does not negate evolutionary novelty of implementations.

Functional-class ambiguity remains a secondary barrier in both systems, especially for members of the Avida task family and the Geb rebel. It does not warrant a universal ontology.

The strongest field-level statement is:

\[
\boxed{\text{SUPPORTED BY REVIEWED CASE SET: artificial evolution can produce genuine finite AFN,}}
\]

\[
\boxed{\text{but published evidence for continuing functional-class expansion remains absent.}}
\]

This is a scoped evidence statement, not a universal claim about all artificial systems and not an incapacity result.

## 26. Next-operation decision

\[
\boxed{\text{G3 — EVENT-HISTORY METHODOLOGY}}
\]

The chief missing object is a longitudinal record that aligns, for each candidate event:

- earliest historical appearance;
- earlier-role comparison;
- heritable carrier/lineage;
- causal functional reconstruction;
- trait-linked adaptive establishment; and
- pairwise functional-class comparison.

This decision does not authorize mechanism research, execution of artificial-life systems, or retrospective aggregation of independent experiments.

## 27. Highest-information next operation

Exactly one next operation is selected: **G3 — EVENT-HISTORY METHODOLOGY**.

Its future question would be how published or deposited artificial-life histories must report and align event chronology, causal function, heredity, adaptation, and class comparison so that recurrence can be decided without platform-wide aggregation. That operation is not performed in this pass.

## 28. Stop condition

Positive-case hunting terminates at this checkpoint. It should not resume merely because another platform has many separately published behaviors, high complexity, or unbounded activity statistics.

Reopening the positive-case search would require a preidentified published candidate that supplies at least one of the following:

1. a continuous history with three or more temporally ordered, semantically reconstructed, trait-linked adaptive function events; or
2. substantially stronger continuing recurrence evidence than Stringmol's two-event benchmark.

Absent such evidence, the program proceeds only to the selected **G3 — EVENT-HISTORY METHODOLOGY** operation. No mechanism contrast is licensed, no hypothesis is created, and no system is classified as OEE by this validation.
